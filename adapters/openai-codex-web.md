# OpenAI Codex Web

Codex web is best supported by repo instructions, repo-scoped skills, and Codex plugin metadata.

This repository provides:

- `AGENTS.md` for repo-level instructions.
- `.agents/skills/openplantbook` as a repo-scoped skill pointer.
- `.agents/plugins/marketplace.json` as a repo-local plugin marketplace.
- `.codex-plugin/plugin.json` for plugin packaging and listing text.
- `CODEX_WEB.md` as a human-readable bridge for Codex web tasks.

Use the canonical skill at `skills/openplantbook/SKILL.md`. Do not maintain a separate Codex-specific copy of the Open Plantbook workflow.
