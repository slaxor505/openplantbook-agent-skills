# Anthropic Claude Web

Claude web is best supported through Project Instructions and Project Knowledge.

This repository provides:

- `CLAUDE_WEB.md` for Claude Project setup and project instruction text.
- `CLAUDE.md` for Claude Code-style repository guidance.
- `skills/openplantbook/SKILL.md` as the canonical Open Plantbook workflow.
- `README.md` and `AGENTS.md` as supporting repository context.

Use `CLAUDE_WEB.md` as the Claude web bridge. Do not maintain a separate Claude-specific copy of the Open Plantbook workflow.
